Jednorazowa próba nieautoryzowanego dostępu

Skanowanie katalogów, sprawdzanie podatności, próby typu path traversal czy SQLi/XSS: może skutkować natychmiastowym i całkowitym zablokowaniem adresu IP na poziomie zapory sieciowej. Zablokowane adresy IP nie są przywracane automatycznie przez systemy czasowe.

Zostałeś zablokowany przez pomyłkę?

Jeśli Twój adres IP został zablokowany w wyniku fałszywego alarmu podczas zwykłego przeglądania treści, jedyną możliwością weryfikacji i przywrócenia dostępu jest bezpośredni kontakt poprzez nasz profil na GitHubie:

GITHUB.COM/KAJOTTE-STUDIO

Politykę bezpieczeństwa
W wiadomości e-mail lub zgłoszeniu podaj:
  • Temat: Prośba o odblokowanie adresu IP
  • Domena: Określ, której domeny dotyczy problem
  • Okoliczności: Krótki opis, przy jakich czynnościach doszło do zablokowania
  • Czas i IP: Twój adres IP oraz dokładny czas zdarzenia (z strefą czasową)

Każde zgłoszenie weryfikujemy ręcznie w logach serwera.
