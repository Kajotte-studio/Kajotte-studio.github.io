Single Unauthorized Access Attempt

Directory scanning, vulnerability probing, path traversal attempts, or SQLi/XSS: may result in immediate and permanent IP address blockage at the firewall level. Blocked IP addresses are not restored automatically by automated timers.

Blocked by Mistake?

If your IP address was restricted due to a false positive during normal browsing, the only way to verify and restore access is direct contact via our GitHub profile:

GITHUB.COM/KAJOTTE-STUDIO

or

Security Policy
Please include the following details in your message:
  • Subject: Request to unblock IP address
  • Domain: Specify which domain is affected
  • Circumstances: Brief description of what triggered the blockage
  • Timestamp & IP: Your IP address and the exact time of the event (with timezone)

Each request is manually verified in the server logs, which takes time. Please be patient — resubmitting requests will not speed up the analysis and may only delay the process.
